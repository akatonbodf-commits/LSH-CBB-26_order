# 2026 CBB \- イベント物販事前注文 & POSレジシステム

イベント会場での物販における混雑緩和とオペレーション効率化を目的とした、**事前注文・キャッシュレス/現金レジ精算・商品引き渡し管理**を一元化したWebアプリケーションです。

サーバー費用ゼロ（完全無料枠）での安定稼働を実現するため、**GitHub Pages（静的フロントエンド）** と **Google Apps Script \+ Google スプレッドシート（バックエンド・データベース）** を分離した構成を採用しています。

---

## 主な機能

### 1\. 来場者向け事前注文画面 (`index.html`)

* **アカウント認証 & 固定会員QRコード発行:**  
  * Gmailアドレスを入力するとユーザーID（`USR-1001` 等）が1対1で発行され、専用のQRコードを生成します。  
  * 複数回に分けて注文した場合でも、会員QRコード画面内の「未決済のご注文」で**商品ごとに個数・金額を自動合算**して表示します。  
  * 会員QRコードはユーザー固有の固定値のため、スクリーンショットを保存しておけばレジ前で通信せずに提示できます。  
* **リアルタイム在庫連動 & カート機能:**  
  * 残り在庫数・購入上限数（`limit`）を自動判定し、在庫切れ商品の選択や上限超過を防止します。  
  * 通信待機中は全画面ローディングスピナーを表示し、二重送信を防止します。  
* **スタッフアカウント自動判別:**  
  * スタッフとして登録されたアカウントで認証した場合のみ、画面上部にスタッフ管理画面へのクイックリンクが表示されます。

### 2\. スタッフ向け管理・POSレジ画面 (`staff.html`)

* **スタッフ認証:**  
  * `staffs` シートに登録されたGmailアドレスとパスコード（PIN）による認証機能を備えています。  
* **レジ決済（POS）タブ:**  
  * 端末の背面カメラを用いた**軽量ライブQRスキャン**（250ms間隔・縮小フレーム解析）およびユーザーIDの手入力検索に対応しています。  
  * 対象ユーザーの未決済注文（`status: 0`）をすべて抽出し、**商品別に個数・小計を合算**して一括会計を行います。  
  * お預かり金額を入力するとお釣りを自動計算し、決済完了時にスプレッドシートへお預かり金額（`received_amount`）を記録します。  
* **商品引き渡し（ピッキング）タブ:**  
  * 決済済みの注文を**ユーザー単位（`USR-xxxx`）で合算**して一覧表示します。  
  * オペレーションミスを防ぐため、ステータスに応じて **「ピッキング開始」→「引き渡し完了」** の順で1ボタンずつ段階的に表示します。  
* **ダッシュボードタブ:**  
  * 総売上金額・有効注文件数・商品ごとの販売数および現在庫数をリアルタイムで集計します。

### 3\. バックエンド自動管理 (`Code.gs` / `Setup.gs`)

* **排他制御（`LockService`）:** 同時注文・同時決済による在庫不整合やデータ上書きを防止します。  
* **高速キャッシュ（`CacheService`）:** 商品一覧データをキャッシュし、アクセス集中時のスプレッドシート読み取り負荷を軽減します。  
* **期限切れ注文の自動キャンセル:** 注文確定から1時間経過しても未決済の注文を10分間隔のトリガーで自動キャンセルし、在庫を自動で戻します。

## システム構成・ファイル一覧

```
├── index.html      # 来場者向け事前注文画面
├── staff.html      # スタッフ向けPOSレジ・引き渡し・売上管理画面
├── staff.css       # スタッフ画面用スタイルシート
├── staff.js        # スタッフ画面用ロジック（QRスキャン・POS・ピッキング・集計）
├── config.js       # GAS APIのURL設定・共通通信ヘルパー・ローディングスピナー制御
└── gas/            # Google Apps Script（スプレッドシートのApps Scriptエディタに配置）
    ├── Code.gs     # APIエンドポイント（doGet / doPost）・在庫計算・DB操作
    └── Setup.gs    # スプレッドシート4シート自動構築・トリガー初期設定スクリプト
```
